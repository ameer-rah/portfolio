RUPlanner is a full-stack Rutgers degree-planning application I built and published: https://ruplanner.app/ (code: https://github.com/ameer-rah/RUPlanner). Its hardest component is a Python planning engine that evaluates degree requirements and course prerequisites to generate semester plans. I exposed that engine through FastAPI and PostgreSQL services and built a Next.js interface for course search, transcript-assisted onboarding, saved plans, and progress tracking. Scheduled catalog refreshes and seat-availability polling keep course data current. This project best shows how I turn a complex, changing ruleset into a usable product across the UI, backend, data model, and deployment workflow.
